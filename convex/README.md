# Convex Backend

This directory contains the Convex backend for the Solid TodoMVC app.

## Files

- `schema.ts` defines the auth tables and the `todos` table.
- `auth.ts`, `auth.config.ts`, and `http.ts` configure Convex Auth.
- `todos.ts` exposes the TodoMVC query and mutations used by the Solid UI.
- `_generated/` is generated by the Convex CLI and should not be edited by hand,
  except for reading `_generated/ai/guidelines.md` before changing Convex code.

## Local Development

Run the app from the repository root:

```bash
pnpm run dev
```

That starts `convex dev` and Vite together. The repo's `predev` script also runs
`convex init` and the Convex Auth setup helper once.

## Backend Rules

- Keep authorization server-side. Public todo functions derive the user with
  `getAuthUserId(ctx)` and never accept a user id from the client.
- Add validators for every Convex function argument.
- Query todos through the indexes declared in `schema.ts`.
- Treat `.collect()` as intentional here: TodoMVC lists are per-user and bounded
  by the UI.
